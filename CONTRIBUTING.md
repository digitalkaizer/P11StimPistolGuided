# Contributing

The immediate priority is not another broad memory scanner.

Useful contributions would include:
- tracing `generated_entities.dl_bin` decode/load in the current game binary,
- identifying the current P-92 Warrant entity and its component graph,
- tracing Warrant lock acquisition/UI to target assignment,
- identifying a local player-only target filter,

When posting findings, label them:
- **CONFIRMED**
- **SUPPORTED**
- **LEADING HYPOTHESIS**

Include a discriminating test where possible.
